# ap-answer-hider

Hides correct/incorrect answer indicators on AP Classroom progress check review pages so you can re-attempt questions without seeing what you got.

## What it hides
- Green/red answer highlighting
- Selected answer (blue letter circle)
- Checkmark / X icons
- Rationale explanation boxes
- Score display

Refresh the page to restore everything.

## Usage

### Bookmarklet
Create a new bookmark and set the URL to the contents of [`bookmarklet.js`](bookmarklet.js), then click it on any AP Classroom question details page.

### Console
Open DevTools (`F12`) → Console, paste the contents of [`hide_answers.js`](hide_answers.js), and hit Enter.
